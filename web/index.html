Query syntax

Write a query

Run a selector such as na[amenity=cafe] on its own. Each selector searches the current viewport, including reference sets.

$cafes = na[amenity=cafe]
Name a set of cafés in view.
$inside = $cafes | within($geometry)
Filter an earlier set. Chain filters with |.
show($inside, $geometry)
Finish a program with named sets by choosing which ones to display.

Define each name once, before use. Separate statements with newlines or ;. A pipe can start or end a line. Start comments with //.

Select features by tag

Refine an earlier set with the same GOQL brackets, for example $named = $cafes | where [name].

n nodes · a areas · w non-area ways · r non-area relations · * all. Combine letters to include several types.

na[amenity=cafe][name]
Both tags must match.
n[shop],a[leisure=park]
Either selector can match.
[name] · [!name]
Present except no · missing or no.
[amenity=cafe,bar] · [access!=private,no]
Any listed value · none (includes missing tags).
[height>12]
Numeric tests use = != < <= > >=.
[ref="007"] · [name='Hyde Park']
Quote spaces or numeric-looking text. Escape quotes with a backslash.
[name=Park*] · [name=*Park] · [name=*Park*]
Starts with · ends with · contains.
[name~"(?i).*park.*"] · [name!~"Old .*"]
Whole-value regex. !~ excludes matches. (?i) ignores case.

Filter by set or membership

except($set)
Remove matching OSM types and IDs.
parents_of($set)
Keep ways or relations with a direct member in the set.
members_of($set)
Keep direct members of the set’s ways or relations.

Membership filters accept a role, e.g. members_of($routes, "stop"). Use "" for an empty role. Omit the role to match any link.

Filter by location

Use an earlier set or $geometry as $ref.

intersects($ref)
Shares any point.
within($ref)
Wholly inside. Interiors must meet.
covered_by($ref)
Wholly inside or on the boundary.
contains($ref)
The reference is within the candidate.
touches($ref)
Meets only at a boundary.
overlaps($ref)
Partly shares area, length or points with a shape of the same dimension.
crosses($ref)
Passes through, like a path entering a park.
within_distance($ref, 150)
At most 150 metres away.
disjoint($ref)
Shares no point with any reference.
Overpass QL syntax
nwr["amenity"="cafe"]({{bbox}});
Choose node, way, rel (relation), nw, nr, wr or nwr.
[key] · [!key] · [key=value] · [key!=value]
Chain tag filters. Quote keys and values containing punctuation.
[name~"station",i] · [name!~"^Old"]
Match or exclude a value pattern. Add ,i to ignore case.
(if:is_number(t["height"]) && number(t["height"]) >= 30)
Test each feature’s tags. Combine comparisons with &&, ||, ! and parentheses.
(south,west,north,east)
Use a fixed box, or set a default with [bbox:s,w,n,e];.
(poly:"lat lon lat lon lat lon")
Filter by a polygon. List at least three vertices.
area[name="England"]->.country;
Look up all areas with this exact name. Add tag filters to narrow it.
map_to_area->.parks; · node(area.parks);
Use selected closed ways or polygon relations as search areas.
(around.stops:150) · (around:150,lat,lon)
Search within metres of a set or point. Append more latitude/longitude pairs to follow a line.
->.a; · (.a; .b;); · (.a; - .b;); · nwr.a.b;
Save, combine, subtract or intersect elements. Union and difference also work on area sets.
node(w.roads); · way(bn.crossings);
Get a way’s nodes or find the ways containing selected nodes.
way(r.routes); · node(r.routes:"stop");
Select direct relation members, optionally by role.
rel(bn.stops); · rel(bw.roads); · rel(br.routes);
Find parent relations of nodes, ways or relations.
foreach.stops->.s { … } · if (near.count(nodes) == 5) { … }
Loop over nodes. Filter a named set with node.stops(around.s:100). Collect matches with (.hits; .near;)->.hits;.
>; · .routes > ->.members;
Expand ways into nodes and relations into their direct nodes, ways and those ways’ nodes.
out geom; · out center; · out count;
Emit shapes, centres or totals. Repeat outputs or select a named set with .stops out count;. body keeps tags, skel omits them. asc sorts by ID within type, qt by location within type.

Settings include [out:json], [bbox:s,w,n,e] and [timeout:seconds]. Start from a bounded selection.

Range timings

    Explore an area

    Move the map to the place you want to explore, then choose Download this area at the top of the map. You can review the download size before confirming.

    Run a query to see matching features. Inside your download, Update on pan can refresh the results as you move. Elsewhere, choose Run query to search manually.

    About Regol Live

    Regol Live searches OpenStreetMap features in the current map view. Choose an example query or write your own, then select a match on the map or in the results to inspect its tags.

    Standalone mode

    Select Run query to start. The Regol engine runs in your browser using WebAssembly and reads the parts of the GeoDesk GOL file it needs. Use Download this area to cache tiles for the visible area ahead of time. For the public planet, the browser downloads compressed Geo-Object Bundle (GOB) tiles and builds their query indexes locally. Features extending outside the view can fetch additional tiles.

    Planet data and the area index are © OpenStreetMap contributors under the Open Database License. The planet GOL and GOB are provided by OpenPlanetData.

    Native mode

    The Regol Live server reads the local GeoDesk GOL file, runs your query, and sends the matching features to your browser.

    Keep Update on pan enabled to refresh the results as you move the map.
